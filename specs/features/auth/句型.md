# auth 句型模型

## 實體概述

- **性質**: Aggregate
- **攜帶狀態**: google_id, email, name, created_at
- **Invariant 清單**: google_id 唯一、email 唯一

## 操作清單

| 操作 | 行為分類 | When Data Table 欄位 | Then Data Table 欄位 | Violation Types |
|------|---------|----------------------|----------------------|------------------|
| Google 登入/註冊 | Creation | google_id, email, name | is_new_user, next_step | （無——「必須持有可用 Google 帳號」為系統邊界外前提，Google OAuth 流程本身把關，不在本系統可測試範圍內） |

## 句型清單

| # | 類別 | 句型 | Handler | 參數槽 |
|---|------|------|---------|-------|
| G1 | Given | → 見系統抽象共用句型 G1 | aggregate-given | user_id, google_id, email, name |
| W1 | When | `使用者以 Google 帳號登入：`（Data Table） | command | google_id, email, name |
| T1 | Then | → 見系統抽象共用句型 T1 | success-failure | violation |
| T2 | Then | `回應應包含 is_new_user 為 <is_new_user>`（首次登入時另加 `，next_step 為 "questionnaire"`） | readmodel-then | is_new_user, next_step |

## 測試分析

### Google 登入/註冊

**等價類劃分**: 2 類——帳號不存在（新使用者，觸發建立）／帳號已存在（既有使用者，觸發登入）
**邊界值分析**: 不適用
**狀態轉移**: User 不存在 → 建立（is_new_user=true）；User 存在 → 登入（is_new_user=false）
**組合覆蓋**: 不適用（僅 1 個判斷維度）
**錯誤推測**: Google Token 驗證失敗屬 Google OAuth 流程本身的錯誤，不在本系統可測試邊界內，不產生 Example

**Examples 規劃**：

| # | 驗證目標 | 額外前置狀態 | 輸入資料摘要 | 預期結果 | 分析維度 |
|---|---------|-------------|-------------|---------|---------|
| 1 | 新使用者首次登入時建立帳號並導向問卷 | （無） | google_id="g-001", email="alice@example.com", name="Alice" | 成功，is_new_user=true，next_step="questionnaire" | 狀態轉移/等價類 |
| 2 | 既有使用者登入時不重複建立帳號 | 需先有使用者 google_id="g-002" | google_id="g-002", email="bob@example.com", name="Bob" | 成功，is_new_user=false | 狀態轉移/等價類 |

> Example 2 不驗證 next_step 的值——Feature 中只有「首次登入導向問卷填寫」的 Rule，非首次登入的導向目標未經確認，不可臆測。
