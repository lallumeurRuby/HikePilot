# plan 句型模型

## 實體概述

- **性質**: Aggregate
- **攜帶狀態**: user_id, route_id, recommendation_id, pdf_url, generated_at + 8 個 section
- **Invariant 清單**: 選定的 route_id 必須存在於使用者當次的推薦結果中

## 操作清單

| 操作 | 行為分類 | When Data Table 欄位 | Then Data Table 欄位 | Violation Types |
|------|---------|----------------------|----------------------|------------------|
| 生成登山規劃書 | Creation | route_id | sections[](section_order, section_name), pdf_url | ROUTE_NOT_SELECTED, ROUTE_NOT_IN_RECOMMENDATION |

## 句型清單

| # | 類別 | 句型 | Handler | 參數槽 |
|---|------|------|---------|-------|
| G1 | Given | → 見系統抽象共用句型 G1 | aggregate-given | user_id, google_id, email, name |
| G2 | Given | `使用者 "<name>" 已取得以下路線推薦結果：`（Data Table） | aggregate-given | route_id, name |
| W1 | When | `使用者 "<name>" 選定路線 "<route_id>" 生成登山規劃書` | command | route_id |
| T1 | Then | → 見系統抽象共用句型 T1 | success-failure | violation |
| T2 | Then | `規劃書應包含以下區塊：`（Data Table） | readmodel-then | section_order, section_name |
| T3 | Then | `規劃書應提供可下載的 PDF 連結` | readmodel-then | — |

## 測試分析

### 生成登山規劃書

**等價類劃分**: 選定路線在推薦結果中（成功）／未指定路線（失敗-ROUTE_NOT_SELECTED）／選定路線不在推薦結果中（失敗-ROUTE_NOT_IN_RECOMMENDATION，直接從 Rule「必須從推薦結果中選定」推導，非臆測）
**邊界值分析**: 不適用（8 大區塊為固定集合，無數量邊界）
**狀態轉移**: 不適用
**組合覆蓋**: 不適用
**錯誤推測**: 選定路線 ID 於系統中根本不存在（非「不在推薦結果中」而是「路線不存在」）屬資料完整性錯誤，Rule 未區分此情境，併入 ROUTE_NOT_IN_RECOMMENDATION 處理，不另開 Example

**Examples 規劃**：

| # | 驗證目標 | 額外前置狀態 | 輸入資料摘要 | 預期結果 | 分析維度 |
|---|---------|-------------|-------------|---------|---------|
| 1 | 選定推薦結果中的路線成功生成規劃書 | 已登入 Alice、已取得推薦結果（含路線 R1、R2） | route_id=R1 | 成功，規劃書含 8 大區塊（依序）+ PDF 連結 | 等價類 |
| 2 | 未指定路線時操作失敗 | 已登入 Alice、已取得推薦結果 | route_id 缺漏 | 失敗，violation=ROUTE_NOT_SELECTED | 等價類 |
| 3 | 選定非推薦結果中的路線時操作失敗 | 已登入 Alice、已取得推薦結果（含路線 R1、R2） | route_id=R99（不在推薦結果中） | 失敗，violation=ROUTE_NOT_IN_RECOMMENDATION | 等價類 |
