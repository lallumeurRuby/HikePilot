# recommendation 句型模型

## 實體概述

- **性質**: Aggregate（Recommendation）+ Gateway（Route，唯讀知識庫）
- **攜帶狀態**: Recommendation(user_id, requested_at, has_matches) + recommendation_route(route_id, rank)
- **Invariant 清單**: 推薦路線數量 0~3 條

## 操作清單

| 操作 | 行為分類 | When Data Table 欄位 | Then Data Table 欄位 | Violation Types |
|------|---------|----------------------|----------------------|------------------|
| 請求路線推薦 | Creation | （無輸入參數，依已登入使用者與已存問卷資料） | routes[](route_id, name), has_matches | UNAUTHENTICATED, PROFILE_INCOMPLETE |

## 句型清單

| # | 類別 | 句型 | Handler | 參數槽 |
|---|------|------|---------|-------|
| G1 | Given | → 見系統抽象共用句型 G1 | aggregate-given | user_id, google_id, email, name |
| G2 | Given | `使用者 "<name>" 已回答問卷：`（Data Table） | aggregate-given | question_code, answer_value |
| G3 | Given | `系統中有以下路線：`（Data Table） | aggregate-given | route_id, name, region, difficulty_level, terrain_*, open_status |
| W1 | When | `使用者 "<name>" 請求路線推薦` | command | — |
| T1 | Then | → 見系統抽象共用句型 T1 | success-failure | violation |
| T2 | Then | `推薦結果應包含 <count> 條路線` 或 `推薦結果應為「無符合資料」` | readmodel-then | count |
| T3 | Then | `推薦結果應包含以下路線：`（Data Table） | readmodel-then | route_id, name |

## 測試分析

### 請求路線推薦

**等價類劃分**: 已登入+問卷完成+有符合路線（成功，1~3 條）／已登入+問卷完成+無符合路線（成功，「無符合資料」）／未登入（失敗-UNAUTHENTICATED）／問卷未完成（失敗-PROFILE_INCOMPLETE）
**邊界值分析**: 符合路線數 = 1（下限）／符合路線數 > 3 時僅取前 3 條（上限截斷，Rule 明定上限為 3）
**狀態轉移**: 不適用（唯讀查詢知識庫 + 建立一筆 Recommendation 紀錄，不改變其他既有實體狀態）
**組合覆蓋**: 不適用（單一輸出維度：符合路線集合）
**錯誤推測**: 問卷「部分」完成已由 profile domain 的 MISSING_REQUIRED_ANSWER 覆蓋，此處只驗證「問卷未完成」這個粗粒度前提，不重複測試 profile domain 的邊界

**Examples 規劃**：

| # | 驗證目標 | 額外前置狀態 | 輸入資料摘要 | 預期結果 | 分析維度 |
|---|---------|-------------|-------------|---------|---------|
| 1 | 有符合條件路線時推薦 1~3 條 | 已登入 Alice、已完成問卷、知識庫有 2 條符合路線 | （無） | 成功，推薦結果包含 2 條路線 | 等價類/邊界值 |
| 2 | 無符合條件路線時顯示無符合資料 | 已登入 Alice、已完成問卷、知識庫路線皆不符合 | （無） | 成功，推薦結果為「無符合資料」 | 等價類 |
| 3 | 符合路線超過 3 條時僅取前 3 條 | 已登入 Alice、已完成問卷、知識庫有 5 條符合路線 | （無） | 成功，推薦結果包含 3 條路線 | 邊界值 |
| 4 | 未登入時請求推薦操作失敗 | （無，未登入） | （無） | 失敗，violation=UNAUTHENTICATED | 等價類 |
| 5 | 問卷未完成時請求推薦操作失敗 | 已登入 Bob，問卷必答題未填完 | （無） | 失敗，violation=PROFILE_INCOMPLETE | 等價類 |
| 6 | 使用者可連續請求推薦（重新推薦） | 已登入 Alice、已完成問卷、先前已請求過一次推薦 | 再次請求推薦 | 成功 | 狀態轉移 |
